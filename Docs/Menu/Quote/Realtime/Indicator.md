# 证券指标（Indicator）

> 所属：导航「行情 → 实时行情 → 证券指标」
> 路由：`/Meta/Finv/Quote/Realtime/FTIndicator`
> 视图：`Web/src/views/Meta/Finv/Quote/Realtime/IndicatorView.vue`
> 列选择组件：`Web/src/views/Meta/Finv/Quote/Realtime/IndicatorColumnPicker.vue`
> 列配置（分组 / 预设 / 格式化）：`Web/src/config/indicatorColumns.ts`
> 菜单 key：`quote-realtime-indicator`（父分组 `quote-realtime`）
> 数据表：`cdeu.finv_quote_secu_indicator`（132 列，一行一证券的最新指标快照，主键 `usc`）
> 接口：[`GET /API/V1/Meta/Finv/Quote/Secu/Indicator/Columns`](../../../API/Cdeu/IndicatorPage.md)（列元数据）、
> [`GET /API/V1/Meta/Finv/Quote/Secu/Indicator/Page`](../../../API/Cdeu/IndicatorPage.md)（分页查询）
> 关联需求：11249（列元数据接口）、11250（分页查询接口）、11251（本页面）
> 写入侧（不在本页操作）：`POST .../Quote/Cdeu/SecuKey/Indicator/Sync/Run`（批量同步上游）、
> `POST .../OpenAPI/V1/Meta/Finv/Quote/Cdeu/Realtime/FTSecuIndicatorUpsert`（采集端回传）

## 1. 业务功能

只读浏览证券指标表。一行 = 一个证券的**最新**指标快照（不存历史），全表 132 列：价格、成交、股本市值、
估值、股息、盘口、区间涨跌、盘前、基金（ETF / 信托）、期货与标的、指数与 24h 统计、时间与来源。

132 列不可能一次铺满屏幕，本页按**三层**组织：主表只显示当前「列方案」选中的列；列选择抽屉按分组勾选；
点行看该证券的全部 132 列。

## 2. 页面构成

### 2.1 筛选与排序

| 控件 | 说明 |
|---|---|
| 关键字 | 模糊匹配 `usc` / `ftmm_symbol` / `name`（回车即查询），可直接输入 `HK.00700` 这种键 |
| 市场 | 全部 / `HK` / `SH` / `SZ` / `BJ` / `US` / `CC` / `FX`；按 `ftmm_symbol` 第一段匹配，切换即查询。`CC`=加密货币、`FX`=外汇/货币指数（口径写在页面底部说明卡片，不进下拉选项） |
| 排序字段 | 可搜索下拉，候选 = 表里全部列（与后端白名单同源），选项**只用中文短名**（如「更新时间」「市盈率TTM」）；默认「更新时间」降序 |
| 方向 | 降序（默认）/ 升序；空值（NULL）一律排在最后 |
| 每页 | 20 / 50（默认）/ 100 / 200；位于表格底部、页码控件左侧 |
| 查询 / 刷新 / 重置 | 与筛选控件同处一行；查询回到第 1 页，刷新按当前条件重取，重置恢复默认条件与默认列方案（概览） |
| 选择列 | 打开右侧列选择抽屉（见 2.2），按钮上方的 chip 显示 `已选 / 全部` 列数与当前方案名 |

### 2.2 列选择（抽屉）

- 每项显示**中文短名** + 列名（`code` 小字），完整口径悬浮可见。
- 按 **13 个业务分组**展示：身份与精度、行情价格、成交与活跃度、股本与市值、盘口与涨跌停、估值、股息、
  区间与极值、盘前、基金（ETF / 信托）、期货与标的、指数与 24h 统计、时间与来源；表里新增但
  `indicatorColumns.ts` 未登记的列自动落到「其它（未登记）」。
- 支持按中文名 / 列名搜索；每个分组有「全选 / 清空」。
- **预设列方案**：概览（默认，22 列）、行情、估值与股息、基金、期货与标的、时间与来源、全部（132 列）。
  手工勾选后方案名变为「自定义」。
- `usc` / `ftmm_symbol` 是行身份列，不可取消（后端也会强制补齐）。
- 勾选结果即时生效并自动重查，同时写入 `localStorage`：

| 键 | 内容 |
|---|---|
| `finvquant.indicator.columns` | 选中列名（逗号分隔） |
| `finvquant.indicator.preset` | 当前预设 key（自定义时为空串） |
| `finvquant.indicator.pageSize` | 每页条数 |

### 2.3 主表

- 列标题=**中文短名**（`indicatorColumns.ts` 的 `label`，如「涨跌幅」「总市值」）。
  表列注释（整句口径，常带括号补充，如「最后更新时间（可空；由触发器 …… 刷新）」）**不进表头**，
  只在悬浮提示里出现：悬浮显示「完整口径｜列名：`xxx`｜口径补充」。
  未登记的列（后端新加、`indicatorColumns.ts` 还没补）才回退显示表列注释原文。
- 左侧三列冻结（横向滚动时固定身份与名称），其余列横向滚动；单元格一律不换行，数值列右对齐并给最小宽度。
- 行末「详情」列（`mdi-open-in-new`）或点行任意位置 → 打开行详情。
- 涨跌只着色 `change_ratio` / `change_price` 两列（红涨绿跌），**不做整行着色**：132 列整行红/绿会读不清。

### 2.4 行详情（对话框）

点行后另行请求该证券的**全部 132 列**（不受当前列方案影响），按分组顺序逐段展开「中文短名 / 列名 / 值」三列，
顶部显示名称 + `usc` + `ftmm_symbol`，并提供「复制 JSON」（整行 wire 数据）。
**对话框里不放任何口径长文本**（表列注释满是括号补充，132 行铺出来只会吵）：
口径统一去页面底部说明卡片的「列口径速查」里查。

### 2.5 展示规则

- 所有值由后端以**文本**返回（保住 `NUMERIC(30,10)` 精度），本页按列口径折算：
  - 价格 / 估值类：最多 4~6 位小数并去尾零；
  - 金额 / 股本 / 成交量类：`万 / 亿 / 万亿` 缩写（如 `2510000000000` → `2.51 万亿`）；
  - 比率类（涨跌幅、换手率、振幅、股息率、区间涨跌等）：库内是百分点数值，直接加 `%`；
  - 时间类：`ts` / `ts_*` / `before_open_exchange_time` 是 epoch 毫秒 → 本地时间；
    `dt_collect` / `dt_create` / `dt_update` 是 `timestamptz` 文本 → 本地时间；
  - 字典列（`price_direct` 等方向、`underlying_instrument_type`）只显示中文，未登记值原样显示；
  - 空值统一 `—`（库里是 NULL，不是 0）。
- 长文本 `json_unmapped`、`secu_url` 走 `ⓘ` 点击浮层（`TextPopover`，可选中复制），单元格只留图标 + 「查看」。

## 3. 说明卡片（页面最底部）

按 `ExplainCardSpec` 收进唯一一张「说明」卡片，五段：表口径 / 列的读法 / 列口径速查 / 与其它页面的关系 / 注意事项。
「列口径速查」是默认收起的折叠面板，按分组列出全部 132 列的「短名 / 列名 / 表列口径注释」——
所有长口径说明的唯一落点。

## 4. 依赖与口径

- 表结构变更（增删列 / 改列名）后**只改两处**：后端无需改动（列来自 `pg_attribute`），
  前端在 `indicatorColumns.ts` 里补该列的分组与格式化口径；未登记列不会让页面报错，只会落到「其它」。
- 指标表里上游 `usc` 为空的记录会用 `ftmm_symbol` 占位（约 3,673 行），本页会出现 `usc = ftmm_symbol` 的行，
  属同步口径而非重复数据。
- 本页只读：写数据走「证券参数同步 → FT证券指标数据同步」或采集端 OpenAPI 回传。
