# 缺省汇率（FxCer）

> 菜单 key：`quote-realtime-fxcer-overview`
> 路由：`/Meta/Finv/Quote/Realtime/FXCEROverview`
> 所属：导航「行情 → 实时行情 → 缺省汇率」
> 视图：`Web/src/views/Meta/Finv/Quote/Realtime/FxCerView.vue`
> 关联需求：10999（本页与接口；表结构 10998）、11000（路由改名 + 矩阵/表格双模式 + 中文名称）
> 关联接口：[`API/Cdeu/FxCer.md`](../../../API/Cdeu/FxCer.md)
> 关联数据表：[`DataDictMapping/FinvFxcer.md`](../../../DataDictMapping/FinvFxcer.md)（`public.finv_fxcer`，V300124）

## 1. 用途

查看并手动更新 `public.finv_fxcer`（缺省汇率表 v2，主键 `usc`）。

- 这张表是多货币环境下把证券市值、成交额等金额**统一到同一计价货币**时的换算来源，
  `rate` = 1 单位源币种折合的目标币种数量；每行带 `usc`（上游 `stockCode`）与中文名 `name`；
- 数据来自 moomoo `get-fx-overview`：72 个货币对（9 币种两两组合）直采，
  需求 11020 起**不再按 `CNH` 派生 `CNY`**（`CNY` 由表格模式的 `get-fx-rate-list` 直采），概览一轮只落 72 行；
- **只保最新、不建历史表**；当前只支持本页手动触发，定期更新后续实现。

## 2. 页面结构

### 2.1 头部操作

| 控件 | 说明 |
|------|------|
| 立即更新 | 同步执行（超时上限 60 s），**按当前模式选择采集来源**（需求 11001）：矩阵模式 → `POST .../Fx/CerSync?source=overview`（get-fx-overview，9 币种完整矩阵）；表格模式 → `POST .../Fx/CerSync?source=rateList`（get-fx-rate-list，`listId=1`、`page=0`、`pageSize=500`，币种更多）。成功后 toast 提示来源与 `收到 / 派生（已停用）/ 新增 / 覆盖` 条数并自动刷新 |
| 刷新 | `GET .../Fx/Cer` 重新拉取整表（不改数据） |

### 2.2 状态告警（主卡片内，表格上方）

| 状态 | 展示 |
|------|------|
| 表为空 | warning 提示「还没有成功更新过汇率，请点击立即更新」 |
| 最新报价 ≥ 24 小时 | warning 提示已过期小时数，建议重新更新（暂无定期任务） |
| 请求失败 | error 展示错误信息；手动更新失败同时弹 error toast |

### 2.3 说明卡片（表格下方，需求 11005／11006）

三段说明文本**统一放在正文内容下方的独立卡片**里，不再出现在标题下方或表格前后；
卡片带标题「说明」（`mdi-information-outline`），正文按「分节标题 + 左侧色条」组织，段间用 `v-divider` 分隔：

| 段落 | 分节标题 | 内容 |
|------|----------|------|
| 表口径 | 「表口径」 | `public.finv_fxcer` 一行 = 一个货币对的最新汇率（`usc` 主键、`name` 中文名）、`rate` 语义、只保最新 |
| 数据源 | 「数据源与互补」 | `get-fx-overview` 72 对、`CNY` 由列表直采且**不再派生**、CNY/CNH 基差提醒；两模式各自来源、互不删除可互补 |
| 矩阵读法 | 「矩阵读法」 | 单元格读法示例、`*` 为历史派生标记、`—` 无该货币对、悬浮看时间与来源（仅矩阵模式显示） |

样式约定：分节标题 `0.875rem / 500 / primary`，正文 `text-body-2`（不透明度 0.85、行高 1.6），
矩阵读法沿用原小字（`text-caption` + `finv-fxcer-name`）。

### 2.4 汇总卡（chip 行）

| 卡片 | 取值 |
|------|------|
| 直采条数 | `flag_derive='0'` 的行数（正常 72） |
| 派生条数 | `flag_derive='1'` 的行数；需求 11020 起正常为 **0**（chip 文案标注「已停用」） |
| 最新报价 | `max(ts_quote)`，按浏览器本地时区显示 |
| 最近更新 | `max(gmt_update)`，按浏览器本地时区显示 |

### 2.5 两种展示模式（右上角切换，默认矩阵模式）

| 模式 | 说明 |
|------|------|
| 矩阵模式（默认） | 行 = 源币种、列 = 目标币种，单元格 = `1 行首币种 = N 列首币种`；**左上角单元格**用一条「左上角连到右下角」的对角线拆成两个区域：右上三角写「目标」（列方向）、左下三角写「源」（行方向），悬浮提示「行 = 源币种，列 = 目标币种」（需求 11012）；目录交叉的对角线单元格（同币种对同币种）显示 `—`；历史派生行才带 `*` 且底色略深（当前采集不再产生）；**汇率数值按 `change_ratio` 着色：涨 `#ff0000`、跌 `#00e676`**（与「证券待录入」表格同一套红涨绿跌配色，0 与无涨跌数据的行不着色，需求 11017）；悬浮显示「币种全名 → 币种全名 / 1 源 = N 目标 / **涨跌额 · 涨跌幅**（提示框内统一使用默认文字色，不按涨跌着色；无数据时提示「表格模式采集后才有」）/ 报价时间 / 直采或派生 · 来源」（需求 11014/11018） |
| 矩阵单元格样式（需求 11013/11014） | **直角矩形**：`border-collapse: collapse` + `border-spacing: 0`，相邻单元格共用 1px 实线边框，**行、列两个方向都有分割线**，单元格之间没有间隙；表头行与行首列底色更深（`surface-variant` 70%，数据格 30%）。悬浮单元格：底色 `primary` 16%、描边 `primary` 55%、`0 2px 10px` 抬升阴影、文字转 `primary` 并加粗；**行首与列首同步高亮**（需求 11015：通过 `hoverSrc`/`hoverDest` 记录悬浮单元格的行/列币种，给行首、列首 `th` 加 `.finv-fxcer-axis-hover`，底色 `primary` 10%、描边 35%、文字转主色加粗，直观体现当前选中的「源币种（行）」与「目标币种（列）」；鼠标移出单元格或整块矩阵时清除）；进出均有 0.15s 过渡（离开不瞬切）。单元格悬浮提示**逐行展示**（币种对 / 汇率 / 报价时间 / 类型·来源各占一行），不再用带 `\n` 的单行文本 |
| 表格模式 | 逐行明细（88 行），列见下表 |

矩阵行列币种顺序固定为 `USD`、`CNY`、`CNH`、`HKD`、`EUR`、`JPY`、`SGD`、`GBP`、`AUD`、`CAD`、`NZD`、`CHF`、`PHP`、`IDR`、`ZAR`、`RUB`、`THB`、`TWD`、`XAU`、`XAG`（需求 11003/11004），其余币种按字母序追加到末尾。
`—` 表示无该货币对：对角线本身，以及上游不提供的 `CNH ↔ CNY`（上游只给 9 币种两两组合）。

### 2.6 表格模式列（不分页，88 行一次展示）

| 列 | 说明 |
|----|------|
| 代码 | **第一列**，`usc`：上游 `stockCode`（如 `USDCNH`） |
| 币种名称 | `name`（简体中文，如 `美元/离岸人民币`）；列表来源直接用上游 `name`，概览行按币种中文名合成 |
| 源币种 / 目标币种 | ISO 4217 代码；`CNY` = 人民币、`CNH` = 离岸人民币（两者存在基差） |
| 缺省汇率 | `rate`，按量级调精度：≥100 保留 4 位、≥1 保留 6 位、<1 保留 8 位（`JPYUSD` 这类需要更多小数） |
| 涨跌额 / 涨跌幅 | `change_price` / `change_ratio`（需求 11016）：只有**表格模式采集来源** `get-fx-rate-list` 提供，矩阵模式来源 `get-fx-overview` 不给这两个字段，故只有经过列表采集的行才有值，其余显示 `—`；涨跌额按同一量级调精度、涨跌幅补 `%` 保留两位；配色**红涨绿跌**（涨 `#ff0000`、跌 `#00e676`，与「证券待录入」一致），0 与空值不着色 |
| 类型 | chip：直采（primary）/ 派生（secondary，仅历史数据；需求 11020 起采集只产生直采） |
| 来源 | `moomoo.get-fx-overview` / `moomoo.get-fx-rate-list` / `derive:CNH` |
| 备注 | 口径说明（当前直采行显示 `—`） |
| 报价时间 | `ts_quote`（Unix 毫秒 → 本地时间）；**放在最后两列** |
| 更新时间 | `gmt_update`；同一轮更新基本一致，可当批次时间；**放在最后一列** |

## 3. 口径与约束

- 表结构、采集口径、换算三级回退见 [`DataDictMapping/FinvFxcer.md`](../../../DataDictMapping/FinvFxcer.md)；
- `insert + update` 可能小于 `rows_receive`：旧报价不覆盖新报价、派生行不覆盖直采行（仍保留该保护，兼容历史派生数据）；
- 本页不做数据编辑：汇率只能由上游采集覆盖，禁止手工改 `rate` / 涨跌两列（会与 `ts_quote` 口径矛盾）；
- 涨跌两列写入用 `COALESCE`：矩阵模式采集（不带涨跌字段）不会清空此前列表模式采到的涨跌值；
- 前端未做分页与筛选：88 行固定集合，直接全量展示；
- **两个来源互补**：概览只有 9 币种两两组合，列表（282 条）币种更多；两者写同一张表、互不删除，
  同货币对按「新报价覆盖旧报价」更新，所以可先跑矩阵模式铺满矩阵，再跑表格模式补长尾币种；
  列表接口不返回报价时间，其 `dt_quote` 为本次采集时刻；该请求不需要 `_` 时间戳参数。
  列表先按 `pageSize=500` 取全，若上游拒绝大 `pageSize`（返回 `code=500`）则自动降级为 `pageSize=50` 分页，
  toast 会显示「（分 N 页）」；列表里的指数序列（`USDindex`/`EURindex`）等非货币对条目会被跳过。
- **CNY 与 CNH 不可混用**：两者存在基差，中文名称为「人民币」「离岸人民币」，靠币种代码区分。
  需求 11020 起 `CNY` 相关货币对只由表格模式的 `get-fx-rate-list` 直采，**不再按 `CNH` 同价派生**
  （派生值等于离岸价、不等于在岸真实价，会污染换算与回测口径）；若矩阵里某格为空，说明还没用列表采集过。
