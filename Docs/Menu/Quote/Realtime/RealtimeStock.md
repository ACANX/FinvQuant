# 证券行情排行（RealtimeStock）

> 所属：导航「行情 → 实时行情 → 证券行情排行」
> 路由：`/Meta/Finv/Quote/Realtime/FTStockRank`
> 视图：`Web/src/views/Meta/Finv/Quote/Realtime/RealtimeStockView.vue`
> 菜单 key：`quote-realtime-ftstockrank`（父分组 `quote-realtime`）
> 数据表：`cdeu.finv_cdeu_secu_realtime_stock`（一行一证券，主键 `stock_id`）
> 接口：[`GET /API/V1/Meta/Finv/Quote/Cdeu/Realtime/Stock/Page`](../../../API/Cdeu/RealtimeStockPage.md)
> 关联需求：10962（菜单）、10963（路由与着色）、10964（更名）、10956–10961（表、写入接口与数值列）

## 1. 业务功能

展示证券**最新一张行情快照**（不是历史序列）：每行一个证券，按 `stock_id` 覆盖更新。
数据由外部采集端通过
`POST /OpenAPI/V1/Meta/Finv/Quote/Cdeu/Realtime/FTStockUpsert`（或内部同路径接口）批量写入，
本页只读。

## 2. 页面构成

### 2.1 筛选与排序

| 控件 | 说明 |
|---|---|
| 关键字 | 模糊匹配 `usc` / `stock_code` / `name`（回车即查询） |
| 市场 | `全部 / HK / SH / SZ / BJ / US`，切换即查询 |
| 币种 | `全部 / CNY / HKD / USD`，切换即查询 |
| 排序字段 | 总市值（默认）、流通市值、成交额、成交量、涨跌幅、涨跌额、AUM、量比、更新时间、证券编号 |
| 方向 | 降序（默认）/ 升序；空值一律排在最后 |
| 每页 | 20 / 50（默认）/ 100 / 200；位于表格底部、页码控件左侧 |
| 查询 / 刷新 / 重置 | 与筛选控件同处一行；查询回到第 1 页，刷新按当前条件重取，重置恢复默认条件 |

### 2.2 表格列

基础信息：`usc`、名称、代码、市场、币种。

价格与涨跌：现价（`price_nominal`）、涨跌额（`change_price`）、涨跌幅（`change_ratio`，百分点数值）。

> 不展示「证券编号」与「方向」两列：证券编号仅作为排序字段保留；涨跌方向改用**整行颜色**表达（见 2.3）。

规模与成交：总市值、成交额、成交量、总股本、流通股本、流通市值、AUM（信托/基金资产规模）。

比率指标：成交额变化率、振幅、量比、买卖比、杠杆。

更新时间：`dt_update`（Unix 毫秒，按浏览器本地时区显示为 `yyyy-MM-dd HH:mm:ss`）。

### 2.3 展示规则

- 金额/股本/成交量等大额数值按 **万 / 亿 / 万亿** 折算（如 `2510000000000` → `2.51 万亿`）；
- 价格与涨跌额保留最多 4 位小数并去尾零；涨幅类统一显示 `x.xx%`（库内是百分点数值，直接加 `%`）；
- 空值显示 `—`，不显示 `null` / `0`；
- **红涨绿跌**：`price_direct` 为 `+` 的整行显示红色、为 `-` 的整行显示绿色（`0`/空为默认色），
  不再单独占用一列（需求 10963）。

## 3. 使用说明

1. 进入菜单后默认按「总市值」降序取第一页 50 条；
2. 输入关键字或切换市场/币种后自动定位到第 1 页；
3. 表格区域可横向滚动（列较多），表头固定；
4. 数据更新由采集端写入，本页不提供编辑入口。

## 4. 注意事项

- **这是快照表**：同一证券只有一行，历史序列请看「历史行情查询」（分钟/日 K 线）；
- `usc` / `currency` 由 `stock_id` 关联 `futu.finv_futu_quote_collect` 与
  `public.finv_security` 回填，**关联不上的行为 NULL**（页面显示 `—`），不做推断性补全；
- `trust_aum` 的单位是「元」，上游带单位文本（万/亿/万亿）在写入侧已换算；
- 若页面报 401，说明登录态失效，重新登录即可；报 400 时按提示检查排序/分页参数（页面本身不会传非法值）。
