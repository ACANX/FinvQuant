# USC 映射规则（UscMapping）

> 菜单 key：`quote-realtime-usc-mapping`
> 路由：`/Meta/Finv/Quote/Realtime/UscMapping`
> 所属：导航「行情 → 实时行情 → USC 映射规则」（紧跟「证券参数同步」之后）
> 视图：`Web/src/views/Meta/Finv/Quote/Realtime/UscMappingView.vue`
> 关联需求：11072（建表 + 后端预演/应用）、11073（页面与菜单）
> 关联接口：[`API/UscMap.md`](../../../API/UscMap.md)、契约 [`API/UscMap.yml`](../../../API/UscMap.yml)
> 关联数据表：`futu.finv_futu_usc_rule` / `futu.finv_futu_usc_rule_item` / `futu.finv_futu_usc_map` /
> `futu.finv_futu_usc_rule_log` / `archive.finv_usc_reuse_snapshot`（迁移 `V300157`）

## 1. 用途

维护「富途代码 → Finv 内部证券代码（usc）」的映射规则，并把规则算出的结果落到
`futu.finv_futu_usc_map`、回写 `futu.finv_futu_secu_key.usc`。

- 规则改完**先预演**，看差异与实际落库口径一致后再应用；
- 应用是异步运行（`run_id` + 日志），同一时刻只允许一个；
- 定时同步默认关闭（`sys_config 20015` 为空），需要时由运维填回 cron。

## 2. 页面结构

### 2.1 头部

| 控件 | 说明 |
|------|------|
| 规则版本 / 条目数 / 键表匹配率 / 定时同步 | `GET .../UscMap/Status` 的快照 |
| 刷新 | 重新拉状态、规则、条目、日志 |

### 2.2 Tab 1「规则」与 Tab 2「条目」

规则层与条目层**分成两个页签**，各自只放自己关心的信息（原先左右分栏杂糅在一起，条目表被挤在窄栏里）。

| 页签 | 内容 |
|------|------|
| **规则** | 10 条规则的只读视图：`rule_no` / 名称 / 类型 / `priority` / 作用域 / 默认动作 / 启用状态 / **条目数（生效/全部）** / 说明；点任意行或「查看条目」→ 切到「条目」页并自动带上该规则过滤。**「说明」列不摊开长文本**：只放一个 ⓘ 图标，鼠标悬浮弹出完整 `rule_desc` + `remark`（无说明时图标置灰），避免长文本把表格撑高变形 |
| **条目** | 条目表：规则 / 市场 / 品种 / 代码 / 正则 / 动作 / 取值 / 状态 / 说明；顶部过滤为**规则 / 市场 / 状态 / 关键字**（规则默认「全部规则」），支持新增、编辑、停用（市场/品种/动作/状态都是带中文的下拉，见下表）。**「说明」列同样是 ⓘ 悬浮**：弹出 `rule_no · 市场/品种/代码`、完整 `item_desc`、出处与备注（规范见 [`TableTextSpec.md`](../../../DevSpec/TableTextSpec.md)） |

- 保存时 `item_desc`（条目说明）**必填**，但**默认自动生成**：按「市场/品种中文 + 匹配键（代码 / 代码正则→替换模板 /
  该范围下全部代码）+ 动作效果（取交易所代码 / 取富途全码（US.SPTSX）/ 固定取 X / 按正则改写 / SH+后四位 / 沿用规则默认）
  + 依据（如 `P40 单点例外`）」拼成一句，用 `｜` 分隔，随表单字段实时刷新；用户可直接改写说明（改写后不再被覆盖），
  字段右侧「重新生成」按钮按当前选择重算；编辑既有条目时不覆盖其历史说明；
- 停用不删行：置 `RETIRED` 并写失效日，可再编辑回 `ACTIVE`；
- `status` / `scope_env` / 生效区间都可在对话框里改；
- 编辑对话框的**动作 / 状态 / 品种**是下拉（品种可自由填写，兼容历史值），选项一律按
  「`值[中文]`」风格显示，如下表。

| 字段 | 选项（`中文[值]`） |
|------|--------------------|
| 市场 `market` | `美股[US]`、`沪市（上交所）[SH]`、`深市（深交所）[SZ]`、`北交所[BJ]`、`港股[HK]`、`加拿大[CA]`、`澳大利亚[AU]`、`日本[JP]`、`新加坡[SG]`、`马来西亚[MY]`、`泰国[THA]`、`加密货币[CC]`、`外汇[FX]`、`板块[BK]`、`债券[BMS]`、`全球[GL]`（16 种取自 `futu.finv_futu_secu_key.market`，中文对齐 `public.finv_market`）；留空 = 通配任意市场 |
| 动作 `action` | `取证券代码[CODE]`、`取富途全码[FTMM]`、`取固定字面量[LITERAL]`、`按正则替换[REWRITE]`、`沪市指数四位码[SH4]`；留空 = 用规则默认动作 |
| 状态 `status` | `生效[ACTIVE]`、`待生效[PENDING]`、`已停用[RETIRED]` |
| 品种 `instrument` | `股票[stock]`、`ETF / 交易所交易基金[etf]`、`指数[index]`、`板块 / 行业分类[sector]`、`大盘 / 市场整体[market]`、`加密货币[crypto]`、`外汇[forex]`、`期货[futures]`；留空 = 通配任意品种 |

**下拉用 `中文[值]`，表格列只显示中文**：条目列表的市场 / 品种 / 动作 / 状态、规则列表的默认动作 / 启用、
预演明细的类别，都只显示字典里那个值（如 `美股`、`取富途全码`、`生效`、`新增`），不带键 `[US]` / `[FTMM]`
—— 键只在**下拉选项**里出现，方便你知道选的是哪个枚举；未登记的值原样显示，避免信息丢失。
顶部筛选的市场也是同一套下拉（首项「全部市场」）。

**动作决定填什么（联动，不摊开全让用户猜）**：选完动作后，对话框只显示这一个动作真正需要的输入，并给一句人话提示。

| 动作 | 额外输入 | 说明 |
|------|----------|------|
| `取证券代码[CODE]` | 无 | 直接用前处理后的 `canon_code` |
| `取富途全码[FTMM]` | 无 | 用 `market.code`（如 `CC.AMPL`） |
| `取固定字面量[LITERAL]` | **固定取值 usc**（必填） | 不管代码是什么，`usc` 写成这里填的字面量（如 `US.XRP`、`IDX.SPX`） |
| `按正则替换[REWRITE]` | **代码正则** + **替换模板**（都必填） | 正则匹配原代码，模板生成新 `usc`（捕获组用 `$1`），此时「代码」输入框隐藏（二者互斥） |
| `沪市指数四位码[SH4]` | 无 | `000300 → SH0300` |
| 留空 | 无 | 按所属规则的默认动作（P40/P50 默认 `FTMM`） |

保存时只提交当前动作相关的取值，其余字段一律置空（切换动作留下的旧值不会落库）。

### 2.3 Tab 2「预演与应用」

| 操作 | 行为 |
|------|------|
| 预演差异 | `GET /Diff/Preview`：返回新增/更新/退市/复用/未变/冲突升级/**键表回写**计数 + `preview_token`（响应只带前 200 行） |
| 明细分页 | `GET /Diff/Page`：按类别（全部/新增/更新/退市）分页浏览**完整明细**；每页 50 条，页大小上限 200。明细缓存在服务端，30 分钟或重新预演后失效 |
| 立即应用 | 只有预演出差异才可用；弹窗填原因后 `POST /Sync/Run`（带令牌），随后 800ms 轮询运行快照 |
| 立即执行一次 | 定时任务的「手动跑一遍」：内部仍是预演取令牌 → 确认 → 应用，与定时执行内容完全相同 |
| 冲突 | 预演报冲突（若有）时应用会被后端拒绝，需先修规则 |

页面最下方是「**定时自动执行**」卡片（`GET/POST /Schedule`）：只决定上面这套动作多久自动跑一次，
不是额外步骤；可改 cron（6 段）或一键关闭，并显示下次执行时间。

明细列含义：`insert`=结果表没有、`update`=`usc` 变了、`retire`=键表已无该证券（退市）、
`reuse_of_ftmm`=这个 `usc` 上一个占用者。

查询与定位（避免几万条差异翻页找一只证券）：

| 位置 | 能力 |
|------|------|
| 本次预演明细 | 顶部关键字框，大小写不敏感地匹配 `ftmm_symbol` / `code` / 当前 usc / 新 usc；配合「类别」下拉（新增/更新/退市/键表回写）一起用 |
| 结果表查询（随时） | 同一个切换按钮里的第二页签，直接查 `futu.finv_futu_usc_map` 在册映射，**不依赖预演**（不需要先预演、也不受 30 分钟缓存限制）；可按状态过滤、按关键字定位，列含 ftmm_symbol / 市场 / 代码 / 品种 / usc / 命中规则 / 依据 / 状态 / 计算时间 |

### 2.4 Tab 3「审计日志」

`finv_futu_usc_rule_log` 倒序分页：时间 / 对象（`rule_item` / `map`）/ 动作 / 主键 / 操作人 / 原因 / 变更摘要。

## 3. 注意事项

- 应用会**真实改写** `futu.finv_futu_secu_key.usc`；生产库执行前先把预演明细交业务确认；
- 首次应用（结果表为空）时「新增」等于键表行数（当前 73,212），并会改写约 1.68 万行键表 `usc`——
  这正是默认关闭定时同步的原因（迁移 `V300158`）；
- `usc` 复用会先把下游历史行归档到 `archive.finv_usc_reuse_snapshot`，归档失败则整次回滚。
