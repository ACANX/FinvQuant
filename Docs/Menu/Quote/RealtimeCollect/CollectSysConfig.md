## 3. 页面行为

| 区域 | 说明 |

| 顶部 chip | 配置项总数、敏感项数量 |
| 分组表 | 按「moomoo 接入 → Supabase 证券参数 → USC 映射规则」三组展示；每行含编号、配置项（敏感项带「敏感」chip）、当前值、值格式 / 说明 / 留空语义、最近修改时间、操作 |
| 当前值 | 非敏感项显示原值；敏感项显示掩码——`20013` 保留项目 ID（`{PROJECT_ID}\|****`）、`20016` 全掩（`****\|****`）；未配置显示「（未配置）」 |

| 刷新 | 重新拉取列表（旧入口改完后用这个同步显示） |

## 4. 安全约定

1. **列表永不含明文**：敏感项只回掩码 + `has_value`。
2. **明文走独立接口且是 base64**：`GET .../Config/Secret?configNo=20013|20016` 返回
   `value_base64`，避免明文直接出现在响应体里被浏览器历史 / 代理日志 / 关键词扫描留存。
3. **需要登录**：三个接口都在需鉴权的 `apiGroup` 下，未登录 401。
4. **不落日志**：后端日志只记 `config_no` 与 `length`，不记值内容。
5. **只能改已存在的行**：`UPDATE` 影响 0 行时返回「配置不存在，请先执行对应种子迁移」，
   服务运行期不会凭空造配置项（其它模块依赖「缺行回退默认值」的语义）。

## 5. 校验口径（与旧入口完全一致，不另立标准）

| 编号 | 校验实现 | 说明 |
|---|---|---|
| 20013 | `syscfg.ParseSupabaseConn` | 两段都非空；PROJECT_ID 长度 6–64 |
| 20014 | `syscfg.NormalizeSupabaseTableName` | 最多两段；首段字母/下划线开头；只允许字母数字下划线 |
| 20015 | `uscrule.ParseSchedule` | 必须 6 段；空串合法（= 关闭） |
| 20016 | `webapi.ParseEd25519PrivateKey` | 私钥可只填中间 base64 主体；非 PEM 明确报「请勿粘贴公钥」 |
| 20018 | `cdeu.ValidateMoomooQuoteProxy` | 启用时 `base_url` 不得为空；空串合法（= 直连） |

## 6. 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面提示「配置项 N 不存在，请先执行对应种子迁移」 | 该环境没跑到发放该配置的迁移 | 确认迁移版本（20013/20014 → `V300142`/`V300143`，20015 → `V300157`，20016 → `V300227`，20018 → `V300231`）后重启服务 |
| 保存 20018 提示「启用代理时必须填写端点地址」 | 填了 `1\|` 却没写地址 | 补全 `{enable}\|{base_url}`，或用空串改回直连 |
| 20016 保存提示「私钥不是合法的 PEM」 | 粘贴了公钥 / 有多余字符 | 只填中间 base64 一行，或通过旧入口粘贴完整 PEM 由前端归一 |
| 改完 20018 采集没变化 | 代理配置**启动时读一次** | 重启服务生效 |
| 「查看」按钮灰掉 | 该项当前没有值 | 先保存一次值 |
