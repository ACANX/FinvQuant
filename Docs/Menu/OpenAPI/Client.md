## 1. 页面职责

把 `/OpenAPI/V1/*` 的接入治理集中到一页：管理**调用方**、签发**凭证**、查看**调用审计**，并能在页面上切换鉴权开关。

三张表一一对应三个 Tab（一个 Tab 只写一张表）：

| Tab | 表 | 说明 |
|---|---|---|
| 调用方 | `open.open_api_client` | 一行 = 一个接入应用（IP 白名单、速率、配额、到期） |
| 凭证 | `open.open_api_credential` | 一行 = 一种认证模式的密钥（静态 Key / AK-SK） |
| 调用审计 | `open.open_api_invoke_log` | 只增不改；按 `sys_config` 19003 保留天数清理 |

## 2. 顶部：鉴权配置

| 控件 | 配置号 | 取值 |
|---|---|---|
| 鉴权模式 | 19001 | `0` 关闭（默认，全放行且不写审计）/ `1` 启用（未通过即 `190xx`）/ `2` 宽松（校验+审计但失败仍放行） |
| 签名时间窗（秒） | 19002 | 30 ~ 3600，默认 300 |
| 日志保留天数 | 19003 | 0 ~ 3650，默认 90（0 = 不清理） |

只读 chips：`19004` 密钥版本 KID、`19005` 加密密钥是否已配置、`19006` 兜底密钥是否已配置（**只显示是否配置，不回显值**）。

保存后 10 秒内生效（进程内短 TTL 缓存），不需要重启。

`19005` 未配置时页面顶部给出提示：静态 Key 可正常签发与使用，AK/SK 签发会被拒（`503` 与鉴权时的 `19010`）。

## 3. Tab 1 调用方

- 查询：关键字（代号 / 名称）+ 分页。
- 列：代号、名称、状态、凭证（生效/全部）、速率、每日配额、IP 白名单、到期、最近更新、操作。
- 新增 / 编辑（对话框）：代号、名称、负责人、联系邮箱、合同编号、白名单、速率、配额、到期、备注。
  - `client_code` 只允许小写字母/数字/`._-`，2~32 位；
  - **新增默认停用**，核对白名单与配额后在列表里点「启用」；
  - 数值字段为负直接报错（`0` 表示不限）。
- 停用调用方会让其**全部凭证立即失效**，因此停用前有二次确认。

## 4. Tab 2 凭证

- 查询：调用方下拉 + 关键字（凭证号 / 公开标识）+ 分页。
- 列：凭证号、调用方、认证模式（静态 Key / AK-SK）、公开标识（前 12 位 + ⓘ 悬浮看完整值）、授权范围（条数 + ⓘ 悬浮看明细）、状态、最近使用、累计调用、操作。
- 操作：
  - **签发凭证**（对话框，两步走）：填调用方/凭证号/模式/授权范围/白名单/到期 → 提交 → 同框切换成「密钥展示」步骤，
    给出 AK（静态 Key）与 SK（AK/SK 模式）+ 各自复制按钮；关闭后不再显示。
  - **轮换**：确认后生成新密钥，旧密钥立即失效（AK/SK 的旧 SK 在签名时间窗内仍可验签）。
  - **停用/启用**：可逆，不改密钥。
  - **吊销**：不可逆，**必须填原因**，留 `dt_revoke` + `reason_revoke`；吊销后不能启用也不能轮换，只能新建凭证。
- 列表**永不**返回 `secret_hash` / `secret_cipher`，只有 `has_secret` 布尔（表示密钥材料是否已写入）。

## 5. Tab 3 调用审计

- 查询：结果（全部/放行/拒绝）、拒绝原因、公开标识（模糊）、分页。
- 列：请求时间、方法、路径、结果、原因、HTTP、耗时（ms）、公开标识、来源 IP、请求 ID。
- 鉴权关闭（19001=`0`）期间不写审计，空态文案已注明。

## 6. 交互与规范约定

- 密钥类信息**只显示一次**，页面任何列表都不回显；因此没有「查看密钥」按钮。
- 长文本（授权范围、白名单、完整公开标识）一律 ⓘ + `v-tooltip`，不铺开表格列。
- 枚举下拉统一「中文[值]」，表格只显示中文（如「静态 Key」「放行」「IP 不在白名单」）。
- 页面底部唯一「说明」卡片，解释三种鉴权模式、状态语义、审计与兜底通道。
- 一次性操作反馈走 toast；停用/吊销等不可逆动作有二次确认。
