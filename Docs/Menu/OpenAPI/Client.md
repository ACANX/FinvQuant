## 1. 页面职责

只做一件事：维护 `open.open_api_client`（一行 = 一个接入应用）。

密钥不在这里签发（去「OpenAPI 凭证」页），审计不在这里看（去「OpenAPI 调用审计」页），
鉴权开关不在这里改（去「OpenAPI 鉴权配置」页）——一个页面只写一张表。

## 2. 列表

- 查询：关键字（代号 / 名称）+ 分页，按 `client_code` 升序。
- 列：代号、名称、状态、凭证（生效/全部）、速率（次/分）、每日配额、IP 白名单、到期、最近更新、操作。
- 「凭证（生效/全部）」由后端子查询统计，用于判断「有凭证但全停用」这类状态。

## 3. 新增 / 编辑（对话框）

| 字段 | 约束 |
|---|---|
| 调用方代号 | 必填；小写字母/数字/`._-`，2~32 位；全局唯一 |
| 名称 | 必填，≤128 字符 |
| 负责人账号 / 联系邮箱 / 合同编号 | 选填 |
| IP 白名单 | 每行一个 IP 或 CIDR；留空 = 不限；裸 IP 自动补掩码 |
| 每分钟上限 / 每日配额 | `0` = 不限；负数直接报错 |
| 授权到期 | 留空 = 长期 |
| 备注 | 选填 |

**新增默认停用**：登记 → 核对白名单与配额 → 在列表点「启用」。

## 4. 状态操作

- **启用 / 停用**：可逆。停用调用方是总闸，其全部凭证立即失效；停用前有二次确认。
- 没有「删除」：调用方是审计与凭证的归属，删掉会丢历史关联；不再使用就保持停用。

## 5. 说明卡片要点（页面底部）

调用方是「谁在调用」的主体、不携带密钥；启用状态是总闸；IP 白名单与凭证白名单取交集；
速率/配额用 Redis 计数（超限 `19008`）；到期后全部凭证按过期拒绝（`19003`）。
