## 1. 页面职责

读写 `sys.sys_config` 19xxx 号段中的三项运行配置，并只读展示三项敏感项是否已配置。

## 2. 可修改项

| 控件 | 配置号 | 约束 |
|---|---|---|
| 鉴权模式 | 19001 | `0` 关闭（默认，全放行且不写审计）/ `1` 启用 / `2` 宽松 |
| 签名时间窗（秒） | 19002 | 30 ~ 3600，默认 300；同时决定 nonce 去重保留时长（2 倍） |
| 审计日志保留天数 | 19003 | 0 ~ 3650，默认 90；`0` = 不清理 |

保存后 **10 秒内生效**（进程内短 TTL 缓存），不需要重启服务。

## 3. 只读项

| 项 | 配置号 | 展示口径 |
|---|---|---|
| 密钥版本 KID | 19004 | 直接显示值（如 `k1`） |
| 凭证加密密钥 | 19005 | 只显示「已配置 / 未配置」 |
| 兼容兜底密钥 | 19006 | 只显示「已配置 / 未配置」 |

这三项属敏感配置，在「系统配置」页维护，本页**不提供编辑**，也**不回显内容**。

`19005` 未配置时页面给出提示：静态 Key 可用，AK/SK 会被拒绝（签发 503 / 鉴权 19010）。

## 4. 推荐上线顺序（说明卡片里也写了）

1. 保持 `19001='0'`（默认，行为与未接入鉴权时完全一致）；
2. 在「OpenAPI 凭证」页登记调用方与凭证；
3. 切到 `'2'`（宽松），观察「OpenAPI 调用审计」里的失败记录，逐个通知调用方改造；
4. 失败清零后切 `'1'`（强制）；
5. 过渡结束清空 `19006` 与环境变量 `FINV_OPENAPI_KEY`。
