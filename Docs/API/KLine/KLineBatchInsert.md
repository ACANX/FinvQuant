# POST /API/V1/Meta/Finv/Quote/DeDup/Secu/KLine/Min/Batch — 批量插入

批量插入 K 线；**任一条冲突整体回滚**，请求内重复键在写库前拦截。

## 请求

- **方法**：`POST`
- **路径**：`/API/V1/Meta/Finv/Quote/DeDup/Secu/KLine/Min/Batch`
- **旧前缀（过渡别名）**：`/API/V1/Meta/Finv/Quote/Secu/KLine/Min` + 相同子路径（切流期保留，P7 后可移除）
- **Content-Type**：`application/json`

### 请求体

```json
{"items":[{"usc":"000001","ts":1792373400,"close":11.48}, ...]}
```

- `items` 条数 1~`FINV_KLINE_MAX_BATCH_ROWS`（默认 5000），超出返回 413（`211201`）。
- 请求内出现重复 `(usc, ts)` → 409（`211102`），不写任何数据。
- 与库内已有键冲突 → 409（`211101`），单事务整体回滚。
- 单条语句最多 3750 行（参数上限分块），分块仍在同一事务内。

### 成功（HTTP 201）

```json
{"inserted":100}
```
