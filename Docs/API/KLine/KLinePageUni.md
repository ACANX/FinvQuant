# GET /API/V1/Meta/Finv/Quote/DeDup/Secu/KLine/Min/PageUni — 条件查询 + 分页（column/row）

查询参数与 `/Page` 完全一致，输出 `column` + `row` 行数组（单元格为字符串或 null）。

## 请求

- **方法**：`GET`
- **路径**：`/API/V1/Meta/Finv/Quote/DeDup/Secu/KLine/Min/PageUni`
- **旧前缀（过渡别名）**：`/API/V1/Meta/Finv/Quote/Secu/KLine/Min` + 相同子路径（切流期保留，P7 后可移除）
- **Content-Type**：`application/json`

### 成功（HTTP 200）

```json
{"code":1,"data":{"cnt":43756,"ps":50,"pn":1,
 "column":["usc","ts","date","time","o","h","l","c","v","t","cr","cp","pa","pv","ext"],
 "row":[["000001","1792373400","20261019","93000",null,null,null,"11.48","392600","4507048","-0.17","-0.02",null,"FTMM",null]],
 "request_id":"B7C63349-EB36-49AB-B16A-E8E1BE475D3B","ts":1792695045},
 "message":"OK"}
```

取值规则：
- `column` 固定 15 项，顺序不可变；
- 非空值统一为**字符串**（含 `ts/date/time`），数值去尾零（`11.480000` → `"11.48"`，`-0.000000` → `"0"`）；
- `cr` 为两位小数文本；NULL 输出 JSON `null`。
