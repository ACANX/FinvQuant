# PATCH /API/V1/Meta/Finv/Quote/DeDup/Secu/KLine/Min/Batch — 批量增量更新

请求体为**数组**；只更新显式传入的字段，`null` 表示写入 NULL。

## 请求

- **方法**：`PATCH`
- **路径**：`/API/V1/Meta/Finv/Quote/DeDup/Secu/KLine/Min/Batch`
- **旧前缀（过渡别名）**：`/API/V1/Meta/Finv/Quote/Secu/KLine/Min` + 相同子路径（切流期保留，P7 后可移除）
- **Content-Type**：`application/json`

### 请求体（数组，不是 `{"items":...}`）

```json
[{"usc":"000001","ts":1792373400,"volume":8888},
 {"usc":"000002","ts":1792373400,"open":10.5,"remark":"修正"}]
```

- 每条必须含 `usc` + `ts`；仅带定位键的条目跳过（不计 `updated`）。
- 未传字段不变；显式 `null` → 写入 NULL（与「未传」区分）。
- `prev_close` 兼容：转为对 `open` 的更新（`open` 同时传且非空时以 `open` 为准）。
- 条目数 ≤ `FINV_KLINE_MAX_LIST_SIZE`；内部按「显式更新列集合」分组，每组一条 `UPDATE ... FROM (VALUES ...)`，VALUES 每列显式类型转换。
- `gmt_update` 由数据库触发器刷新。

### 成功（HTTP 200）

```json
{"updated":2}
```
