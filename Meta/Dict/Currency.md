# 货币字典（Currency）

> 所属：FinvQuant 元数据字典 · 存放：`Meta/Dict/Currency.md`
> 用途：前端菜单「行情 → 实时行情 → 缺省汇率」（`/Meta/Finv/Quote/Realtime/FXCEROverview`）**表格模式**中
> 「源币种」「目标币种」两列取值的字典：**三位大写字母为键，规范中文名称为值**。
> 数据来源：`public.finv_fxcer`（`V300124`）中的 `currency_src` / `currency_dest` 去重集合，
> 名称取服务端 `cdeu.FxCERCurrencyNames` 与行内 `name`（上游 `get-fx-rate-list` 的 `name`）。
> 关联：[`Docs/DataDictMapping/FinvFxcer.md`](../../Docs/DataDictMapping/FinvFxcer.md)、[`Docs/Menu/Quote/Realtime/FxCer.md`](../../Docs/Menu/Quote/Realtime/FxCer.md)。

## 1. 说明

- 键：ISO 4217 三位字母代码（大写）；`CNH` 为离岸人民币（非 ISO 4217，市场惯例代码），`XAU` / `XAG` 为贵金属现货代码。
- 值：规范中文名称（ISO 4217 中文名优先；`CNH`、`XAU`、`XAG` 按业务口径命名）。
- 排序：先按缺省汇率页矩阵模式的展示顺序（`USD`…`XAG`），其余未列入顺序的币种按字母序排在后面。
- 该字典**只覆盖缺省汇率表当前出现的 36 个代码**；新增币种时须同步本文件与代码里的 `FxCERCurrencyNames`。

## 3. 维护约定

- 新增/下线币种以 `public.finv_fxcer` 实际出现的代码为准（`SELECT DISTINCT currency_src FROM public.finv_fxcer UNION SELECT DISTINCT currency_dest ...`），
  不允许凭上游文档臆造未落库的代码。
- 名称以「规范中文名」为准，口语简称写进「备注」，避免同一代码出现两种展示值。
- 派生行（`flag_derive='1'`）不引入新代码：只把 `CNH` 换成 `CNY`，因此 `CNY` 的值语义始终是「人民币（在岸）」。
